## 디자인 토큰 예외 사유

Provider별 배경색, 텍스트 색상, 아이콘 오프셋은 각 브랜드사의 고유 가이드라인을 따르는 고정 값입니다. Semantic 토큰으로 승격하기에는 재사용성이 낮아 Primitive/Semantic 토큰을 참조하지 않고 직접 값을 사용합니다.

아이콘 오프셋(`iconOffset`) 값은 각 로고 원본의 내부 여백 차이를 보정하기 위한 것으로, 스페이싱 토큰이 아닌 개별 조정 값입니다.

## 접근성

버튼이 비활성 상태일 때 네이티브 `disabled` 속성 대신 `aria-disabled`와 `onClick` 차단 방식을 사용합니다.
