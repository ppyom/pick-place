# BookmarkCount

Pick의 북마크 수를 표시하는 순수 표시용 컴포넌트입니다. 클릭 인터랙션이 필요한 경우 `features/toggle-bookmark`의 `BookmarkToggleButton`이 이 컴포넌트를 감싸서 사용합니다.

## 기본 사용

<Canvas of={BookmarkCountStories.Plain} />

## Variant

배경/테두리 스타일을 결정합니다.

## Active

선택(북마크됨) 상태를 표시합니다. `variant`별로 강조 색상이 다르게 적용됩니다.

<table>
  <thead>
    <tr>
      <th>Variant</th>
      <th>Active 시 스타일</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>`plain`</td>
      <td>텍스트 색상만 `text-text-brand`로 변경</td>
    </tr>
    <tr>
      <td>`filled`</td>
      <td>배경 `bg-surface-brand`, 텍스트 `text-text-on-brand`</td>
    </tr>
    <tr>
      <td>`outline`</td>
      <td>테두리 `border-border-brand`, 텍스트 `text-text-brand`</td>
    </tr>
  </tbody>
</table>
