# Textarea

여러 줄 텍스트를 입력받는 폼 컨트롤입니다. `Default` / `Error` / `Disabled` 상태를 지원하며, `forwardRef`를 지원해 React Hook Form 등 폼 라이브러리와 연동할 수 있습니다.

## Usage

### 기본 사용

```tsx
<Textarea placeholder="장소에 대한 설명을 적어주세요" />
```

### 에러 상태

```tsx
<Textarea status="error" defaultValue="10자 이상 입력해주세요" />
```

### React Hook Form 연동

`forwardRef`를 지원하므로 `register`를 그대로 스프레드할 수 있습니다.

```tsx
const { register } = useForm();

<Textarea {...register('description')} placeholder="설명" />;
```
