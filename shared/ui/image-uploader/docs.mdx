# ImageUploader

이미지 파일을 선택하고 미리보기를 보여주는 범용 컴포넌트입니다.

파일 선택 다이얼로그를 열고 선택한 이미지를 즉시 미리보기로 표시합니다. 크롭/리사이즈 기능은 포함하지 않으며, 파일 선택과 미리보기까지만 처리합니다.

## 사용 예시

```tsx
import { ImageUploader } from '@/shared/ui/image-uploader';

function AvatarField() {
  const [file, setFile] = useState<File | null>(null);

  return (
    <ImageUploader
      shape="circle"
      size="md"
      value={profile.avatarUrl}
      onChange={(file) => {
        setFile(file);
        // 업로드 로직 호출
      }}
    />
  );
}
```

## 접근성

- 클릭 영역 전체가 `role="button"`으로 지정되어 있으며, 키보드로도 Enter/Space 키를 통해 파일 선택을 트리거할 수 있습니다.
- `disabled` 상태에서는 `aria-disabled` 속성과 함께 클릭/키보드 트리거가 차단됩니다.
- 미리보기 이미지는 컨테이너의 `aria-label`이 의미를 설명하므로 장식 이미지로 처리하여 `alt=""`를 사용합니다.

## 주의사항

- 크롭/리사이즈는 지원하지 않습니다. 필요한 경우 별도 컴포넌트/로직으로 처리해야 합니다.
- 선택된 파일의 유효성 검증(크기, 포맷 등)은 컴포넌트 책임 범위 밖이며, 호출부에서 처리해야 합니다.
