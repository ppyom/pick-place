# CollageThumbnail

이미지 배열을 받아 개수에 따라 2x2 그리드로 배치하는 콜라주 썸네일 컴포넌트입니다. 셀 렌더링은 `Thumbnail`에 위임하고, 개수별 그리드 배치와 `+N` 오버레이만 담당합니다.

<Primary />

## 사용 예시

```tsx
<CollageThumbnail images={pick.imageUrls} alt={pick.title} className="size-40" />
```

## 참고사항

- 4장을 초과하는 이미지는 렌더링되지 않고, 마지막 칸의 오버레이로만 개수가 표시됩니다.
- 각 셀은 `Thumbnail`을 재사용하되 `rounded-none`으로 오버라이드하여 각지게 표시하고, 바깥 컨테이너의 `overflow-hidden`으로 전체 라운드 모양을 유지합니다.
