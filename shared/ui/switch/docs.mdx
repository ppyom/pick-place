# Switch

켜짐/꺼짐 상태를 토글하는 폼 컨트롤입니다. 공개 여부처럼 두 상태 중 하나를 즉시 반영해야 하는
경우에 사용합니다. 항상 `checked` / `onCheckedChange`로 외부에서 제어하는 Controlled
컴포넌트이며, 네이티브 `<input type="checkbox">` 대신 `role="switch"` 버튼으로 구현했습니다.

## Controlled 사용

`checked`와 `onCheckedChange`를 직접 상태와 연결해서 사용합니다.

<Canvas of={SwitchStories.Controlled} />

```tsx
const [checked, setChecked] = useState(false);

<Switch checked={checked} onCheckedChange={setChecked} />;
```

## Usage

### 기본 사용

```tsx
<Switch checked={isPublic} onCheckedChange={setIsPublic} />
```

### Label과 함께 (Field)

도메인 지식 없는 범용 `Field` + `Label`과 조합해서 사용합니다.

```tsx
<Field>
  <Label htmlFor="is-public">공개 여부</Label>
  <Switch id="is-public" checked={isPublic} onCheckedChange={setIsPublic} />
</Field>
```

### React Hook Form 연동

네이티브 input이 아니라 `ref`를 받지 않으므로 `register` 대신 `Controller`로 연결합니다.

```tsx
const { control } = useForm();

<Controller
  name="isPublic"
  control={control}
  render={({ field }) => <Switch checked={field.value} onCheckedChange={field.onChange} />}
/>;
```
