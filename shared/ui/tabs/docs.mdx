# Tabs

`items` 배열을 받아 렌더링하는 config-driven 탭 컴포넌트입니다. 내부 상태를 갖지 않는 완전 제어(controlled)
컴포넌트로, 현재 선택된 값(`value`)과 변경 핸들러(`onChange`)를 상위에서 관리합니다.

## 스타일

선택된 탭은 `Text/Brand` 색상 텍스트에 `Border/Brand` 밑줄이 표시되고, 나머지 탭은 `Text/Tertiary` 색상으로
표시됩니다. 탭 바 전체 하단에는 `Border/Default` 구분선이 깔립니다.
