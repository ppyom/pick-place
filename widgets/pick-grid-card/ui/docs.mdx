# PickGridCard

탐색/검색 결과 그리드에서 사용하는 Pick 카드 컴포넌트입니다. `CollageThumbnail`, 제목, 작성자(`Avatar`+이름), 북마크 토글(`BookmarkToggleButton`)로 구성됩니다.

## 긴 제목

제목은 `line-clamp-2`로 최대 2줄까지 표시됩니다. 1줄일 때도 하단 작성자/북마크 영역은 항상 카드 맨 아래에 고정되도록 `flex-1` + `justify-between`으로 처리했습니다.

## 그리드에 여러 개 배치

실제 탐색 페이지처럼 여러 카드가 그리드로 배치됐을 때, 제목 줄 수가 다른 카드들 사이에서도 하단 정보가 정렬되는지 확인할 수 있습니다.
