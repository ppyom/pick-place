# CategoryFilterBar

탐색 페이지 상단에서 사용하는 카테고리 필터 바입니다. Chip 목록을 가로 스크롤로 보여주며, 선택된 카테고리를 강조합니다.

## 특징

- 카테고리 목록(`categories`)은 외부에서 props로 주입받습니다. 하드코딩된 카테고리가 없어 재사용 가능합니다.
- 선택 상태(`selectedId`)는 controlled입니다. 컴포넌트 내부에 상태를 두지 않고, 클릭 시 `onSelect` 콜백만 호출합니다.
- 가로 스크롤 시 스크롤바는 시각적으로 숨김 처리됩니다.

## 사용 예시

```tsx
const [selectedId, setSelectedId] = useState('all');

<CategoryFilterBar
  categories={[
    { id: 'all', label: '전체' },
    { id: 'restaurant', label: '맛집' },
  ]}
  selectedId={selectedId}
  onSelect={setSelectedId}
/>;
```
